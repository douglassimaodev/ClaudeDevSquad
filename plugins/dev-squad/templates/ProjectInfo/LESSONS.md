# Lessons

One rule per mistake already made in this project. Seniors add to it; juniors read it before every task.
`Scope: stack` lessons apply to any project on this stack: the orchestrator offers them for promotion into the dev-squad plugin skills, then marks them `Promoted: <plugin version>`.
